# ChatApplication Frontend

React/Vite client for ChatApplication. It handles Google sign-in, protected routing, contacts, chat requests, realtime messaging, image previews, reactions, replies, profile settings, notification preferences, and themes.

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm test
```

## Environment

Copy `.env.example` to `.env` and set:

```text
VITE_BACKEND_URL=http://localhost:4000
VITE_SOCKET_URL=ws://localhost:4000
VITE_GOOGLE_AUTH_CLIENT_ID=your_google_web_client_id
```
